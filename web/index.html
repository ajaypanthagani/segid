How to use this
  1. Paint an object. Press New object before painting another one. Things that touch count as one object.
  2. Use Cut to draw a line across an object. Nothing is split yet; it only marks where a part could separate. The model sees no difference until a part moves.
  3. Use Move and drag a part away from what it touches, then hold still for a second. Dragging it over something hides what it covers, so drag it clear.
  4. Paint something similar and cut and move it too. After a few examples the Predicted view starts separating seams before anything moves.

Formal shows only what has been seen to separate. Predicted adds what the model has learned about which seams tend to separate: orange ticks mark places where it expects a split, and a box appears once a whole outline is marked. It needs roughly 5 to 10 examples before it starts.
